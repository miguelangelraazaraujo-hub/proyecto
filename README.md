# AniBeat

## Descripción

AniBeat es una página web en desarrollo que combina tres conceptos principales:

1. **Base de datos de música de anime**: Proporciona información detallada sobre canciones de anime, incluyendo autor, álbum, anime al que pertenece, título y otros datos relevantes.
2. **Red social temática**: Los usuarios podrán registrarse, iniciar sesión, buscar información sobre sus canciones favoritas, leer noticias relacionadas con el mundo del anime y sus bandas sonoras, debatir en foros y escuchar canciones directamente desde la plataforma.
3. **Juego diario "AniGuess"**: Cada día se mostrará una canción aleatoria, y los jugadores deberán adivinar tanto el título como el anime al que pertenece.

## Estado del proyecto

En desarrollo.

## Requisitos

Para usar AniBeat solo se necesita:

* Un navegador web moderno.
* Acceso a internet.

Para instalación local (solo con fines de desarrollo o pruebas):

* Descargar los archivos del repositorio (HTML, CSS, JavaScript, imágenes y videos).
* Abrir el archivo principal `.html` en un navegador.

## Instalación

No se requiere instalación para usuarios finales, ya que se tratará de una página web alojada públicamente.

Para instalar localmente:

1. Clona o descarga este repositorio.
2. Abre el archivo principal `index.html` en tu navegador.
3. Asegúrate de mantener la estructura de carpetas (CSS, JS, imágenes y multimedia).

## Uso

AniBeat está diseñada para ser intuitiva y fácil de usar:

* Navega por el catálogo de canciones de anime mediante los menús o el buscador.
* Explora la información de cada canción, incluyendo intérpretes, álbum, anime asociado y más.
* Inicia sesión o regístrate para participar en foros, guardar favoritos y personalizar tu experiencia.
* Lee noticias actualizadas sobre el mundo del anime y su música.
* Participa diariamente en el reto **AniGuess** e intenta adivinar la canción sorpresa del día.
